# VisionVault

VisionVault is a lightweight image discovery application designed to provide quick visual inspiration across various topics using responsive grid layouts.

## Features Built (Part 1)
- Structured semantic HTML header, search form, and accessibility labels.
- Responsive layout styled with custom CSS variables (Teal & Slate theme).
- Auto-flowing responsive CSS Grid container using `repeat(auto-fill, minmax(220px, 1fr))`.

## Key Design Decisions
1. **Category Chips Row:** I added a quick-pick category row so users can instantly search popular topics (e.g., Nature, Architecture) without typing.
2. **Empty-State Messaging:** I included a dashed empty-state section and a status bar to guide the user on what to do when no images are currently loaded.
